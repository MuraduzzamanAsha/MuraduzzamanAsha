Academic Research

SECURITY RESEARCH

Undergraduate thesis research applying static code analysis and machine learning classifiers to defend modern software supply chains.

UNDERGRADUATE RESEARCH TOPIC

Malicious Package Detection in Open Source Ecosystems Using Static Analysis & Machine Learning

Software supply chain security has emerged as a critical attack surface where adversaries publish malicious packages (via typosquatting, dependency confusion, and credential stealers) into registries like npm and PyPI. This research evaluated automated static triage heuristics combined with supervised machine learning algorithms to detect malicious characteristics before runtime deployment.

STAGE 01

Threat Modeling

Categorizing supply chain attack vectors: obfuscation, reverse shells, env scraping, and beaconing.

STAGE 02

AST Static Parsing

Extracting Abstract Syntax Tree node metrics, entropy, eval() usage, network calls, and child process spawns.

STAGE 03

ML Classification

Training classifiers (Random Forest, SVM) on labeled datasets of benign and verified malicious packages.

STAGE 04

Defensive Pipeline

Designing early detection metrics for CI/CD dependency review and pre-installation auditing.
